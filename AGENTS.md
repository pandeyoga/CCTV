# AGENTS.md — rules for any AI/human session working in this repo

Read in this order before changing anything: `docs/STATUS.md` → `docs/DECISIONS.md` → `docs/ARCHITECTURE.md` → `docs/DATA_MODEL.md` → `docs/CONTRACTS.md`.

## Non-negotiables
1. **One source of truth per concept.** See the SSOT table below. Never re-declare a schema, enum, or ID format elsewhere; import or generate from the SSOT. If something must be mirrored across languages (Python ↔ TypeScript), add a test that fails on drift.
2. **No fictional data.** No fake benchmarks, accuracy numbers, sample datasets, or "example results". Synthetic fixtures are allowed only in tests and must be labelled synthetic.
3. **Only claim what was run.** `docs/STATUS.md` lists tests that were actually executed with their result. If you did not run it, write "not run".
4. **Work the active stage only.** Do not pre-build later stages "while you're at it". Interfaces for later stages are fine; implementations are not.
5. **Identity comes from server auth.** Edge payloads never carry `tenant_id` / `store_id` / `device_id`. Any code that trusts those from a request body is a bug.
6. **Time:** store UTC (tz-aware). `event_ts` (when it happened at the edge) ≠ `received_at` (server). Display in the store's IANA timezone.
7. **Secrets** (API keys, RTSP URLs) come from environment only; never in YAML, code, tests, logs, or docs. Use `edge_agent.redact` when logging anything that could contain them.
8. **Every stage ends by updating** `docs/STATUS.md` (what changed, how to run, tests run, limitations, next) and `docs/DECISIONS.md` (new ADRs). Also update `memory/PRD.md`.
9. **Don't refactor beyond the task.** Don't "improve" adjacent code. Don't add fallbacks for impossible cases.
10. **Naming is fixed** (see below). Do not introduce synonyms (`cam_id`, `shop_id`, `enter/entry/in`...).

## Fixed vocabulary
- `tenant_id`, `store_id`, `camera_id`, `device_id`, `line_id`, `event_id`, `track_id` — exactly these names.
- `event_type ∈ {"enter", "exit"}` — never `in/out`, `entry`, `ingress`.
- `event_ts` = when the crossing happened (UTC). `received_at` = server receive time (UTC).
- `camera_id` and `line_id` in edge payloads are the **external string ids** configured on the device; the backend maps them to rows scoped to the authenticated device's store.
- Normalized coordinates: `0..1`, origin top-left, y down. Line direction `a→b`; `enter_side ∈ {"left","right"}` relative to that direction.
- Health status: `ok | degraded | source_down | auth_failed | buffer_full`.

## Environment notes (this preview workspace)
- Backend must expose routes under `/api`, bind `0.0.0.0:8001`; frontend uses `REACT_APP_BACKEND_URL`. Docker Compose cannot run here; it targets the user's machine (ADR-009).
- Use `yarn`, never `npm`. Add Python deps via `pip install` + `pip freeze > backend/requirements.txt` for the backend service only; the edge agent has its own `pyproject.toml`.
