### Config / migration steps for an existing deployment
1. `alembic upgrade head` (adds `dashboard_users`, `tenant_memberships`, device `hb_*` + `last_heartbeat_at`, `count_events.tracking_session_id`). Downgrade exists.
2. Set `JWT_SECRET` (≥ 32 chars) — the API refuses to start without it unless `DASHBOARD_AUTH=disabled` is set explicitly. Remove `DASHBOARD_READ_KEY` / `REACT_APP_DASHBOARD_KEY` (ignored/removed).
3. Create dashboard users: `DASHBOARD_PASSWORD=… python -m app.users create --email … --tenant "<tenant name>"`.
4. Update edge agents (heartbeat thread starts automatically when `backend.url` is configured; `backend.heartbeat_interval_s` default 60). Old agents keep working (`tracking_session_id` optional) but show as **"Belum diketahui"** until upgraded.
